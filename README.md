# Portfolio — Emerson Talles

Sitio estático (HTML + Tailwind CDN) en ES / PT / EN.

## Estructura
- `index.html`, `perfil.html`, `Proyectos.html`, `contacto.html`
- `site.css` — header, footer, chips, diálogo, formulario
- `site.js` — idioma (diccionario `D`), menú móvil, filtros, detalle de proyecto, formulario
- `img/` — fotos de perfil

## Publicar en GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Completar traducciones
Cambia a PT o EN y ejecuta `__i18nMissing()` en la consola: lista los textos aún sin traducir para añadirlos a `D` en `site.js`.
